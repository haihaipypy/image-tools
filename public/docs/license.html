关于 Upscayl

放大功能的交互形态参考了 Upscayl， 但代码是重写的，没有复制它的源码，推理层也完全不同 —— Upscayl 是 Electron + ncnn 原生二进制，本项目是纯浏览器里的 ONNX Runtime。

因此本项目不受 Upscayl 的 AGPL-3.0 传染，按 MIT 发布。

关于 bg0

抠图功能的交互与 API 设计参考了 bg0（Apache-2.0）， 但推理层是独立实现的。

bg0 经 @huggingface/transformers 自带一份 ONNX Runtime， 而本项目直接复用站内已有的 ORT 运行时与自托管 wasm，不引入第二份推理引擎。 因此本项目的依赖树里没有 @huggingface/transformers， 也没有 @bg0/browser。

隐私

图片数据全程留在你的浏览器里，没有任何上传步骤。站点也不记录图片内容或元数据。 唯一的外部请求是首次加载抠图模型时从 HuggingFace 拉取权重。
